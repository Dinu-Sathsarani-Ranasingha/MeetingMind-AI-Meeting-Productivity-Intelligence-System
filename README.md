## 📌 Project Overview

Meetings are essential for collaboration, but many organizations lose valuable time due to unstructured discussions, forgotten action items, and lack of follow-up.

**MeetingMind AI** is an intelligent web application that automatically analyzes meeting transcripts, extracts action items, measures meeting effectiveness, detects recurring issues, and provides productivity insights through an interactive dashboard.

This project combines **Business Analysis**, **Artificial Intelligence**, **Natural Language Processing (NLP)**, **Project Management concepts**, and **Full-Stack Development** into one enterprise-inspired solution.

---

# 🎯 Business Problem

Technology companies often face challenges such as:

- Forgotten action items after meetings
- No way to measure meeting productivity
- Repeated unresolved issues
- Manual meeting documentation
- Lack of team productivity analytics

MeetingMind AI addresses these challenges using AI-driven automation and analytics.

---

# 💡 Solution

MeetingMind AI enables users to:

- Upload or paste meeting transcripts
- Automatically extract action items
- Detect owners and deadlines
- Generate a Meeting Productivity Score (0–100)
- Identify recurring issues across meetings
- Track meeting history
- View productivity trends through dashboards
